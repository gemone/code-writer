Explain design patterns and language idioms.

## Steps
1. Search for the pattern using `lang_search(query: "<pattern>", language: "<lang>")`
2. Look up related stdlib APIs if applicable
3. Provide explanation with:
   - What the pattern does
   - When to use it
   - Code examples
   - Anti-patterns to avoid
4. Validate any generated examples with LSP diagnostics

## Usage
`/explain-pattern observer typescript`
`/explain-pattern decorator python`

Arguments: `<pattern-name> [language]`
