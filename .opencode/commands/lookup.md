Look up language syntax, stdlib APIs, or coding patterns.

Use the `lang_ref` MCP tool to find standard library APIs:
- `lang_ref(language: "$ARGUMENTS")` for full language reference
- `lang_ref(language: "<lang>", module: "<module>")` for specific module
- `lang_ref(language: "<lang>", module: "<module>", method: "<method>")` for specific method

Use `lang_search(query: "<query>", language: "<lang>")` to search for patterns and idioms.

Arguments: `<language> [module] [method]` or `<language> <query>`
